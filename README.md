## Что это

Один HTML-файл, который открывается в браузере и работает без интернета. Внутри — шесть модулей в едином интерфейсе. Данные не покидают устройство: ни аналитики, ни серверов, ни внешних API.

Инструмент создан для практикующих врачей, ординаторов и исследователей. Не заменяет клиническое суждение — формализует и ускоряет рутинные операции: подсчёт баллов по шкалам, подготовку данных для научной работы, экспорт в CSV, печать карты осмотра на A4.

## Что внутри

### 💬 Ассистент клинической коммуникации

102 навыка, сгруппированных в 15 этапов приёма: от начала контакта до завершения консультации. Каждый навык снабжён пояснениями «Зачем» и «Связь с другими этапами». Прогресс сохраняется локально, экспорт в CSV.

### 🧠 Неврологические шкалы

- **NIHSS** — тяжесть инсульта, 15 пунктов, 0–42
- **mRS** — модифицированная шкала Рэнкина, 0–6
- **VAS** — визуально-аналоговая шкала боли, 0–10

### 🦴 Вертебрологические шкалы

- **ODI** — Oswestry Disability Index, 10 разделов, 0–50
- **NDI** — Neck Disability Index, 10 разделов, 0–50
- **Шкала Тампа (TSK-17)** — кинезиофобия, 17 пунктов, 17–68. Пункты 4, 8, 12, 16 — инверсные
- **PCS** — шкала катастрофизации боли, 13 пунктов, 0–52. Три субшкалы

### 🧪 Психо-скрининги

- **HADS** — госпитальная шкала тревоги и депрессии, 14 пунктов, две субшкалы по 0–21
- **PSQI** — Питтсбургский опросник качества сна, 7 компонентов, 0–21. Оригинальные формулы Buysse (1989)

### 🛠 Офлайн-утилиты

Счётчик текста · JSON-форматирование · SHA-256 · генератор паролей · конвертер цветов · дата и время.

### 📚 База знаний

Открытые источники: рекомендации Минздрава РФ, ВОЗ, NICE, EAN, MDCalc, PubMed, Cochrane Library, профессиональные сообщества. Поиск и фильтр по категориям.

Вариант 2. Развернуть на хостинге
Любой статический хостинг: GitHub Pages, Netlify, Cloudflare Pages, nginx, Apache. Backend не требуется.

Архитектура
Один HTML-файл. Всё inline: CSS в <style>, JS в <script>. Нет сборки, нет npm, нет CDN.

text

│                                             │
│  CSS токены  │  HTML 8 панелей  │  Vanilla  │
│              │                  │    JS      │
│                                             │
│  ┌────────────────────────────────────┐     │
│  │  Хранение                          │     │
│  │  localStorage → черновик, шкалы    │     │
│  └────────────────────────────────────┘     │
│                                             │
│  ┌────────────────────────────────────┐     │
│  │  Криптография                      │     │
│  │  SHA-256 (Web Crypto API)          │     │
│  └────────────────────────────────────┘     │
└─────────────────────────────────────────────┘
Нет: React, Vue, jQuery, Bootstrap, Tailwind, Webpack, npm, внешних шрифтов, внешних CDN.

Есть: Vanilla JS (ES2017+), CSS Custom Properties, Web Crypto API, localStorage.

Безопасность
CSP в шапке файла:

text
default-src 'none';
style-src 'unsafe-inline';
script-src 'unsafe-inline';
img-src data:;
font-src data:;
base-uri 'none';
form-action 'none';
object-src 'none';
frame-src 'none';
connect-src 'none';
Что это значит:

connect-src 'none' — приложение физически не может отправить данные никуда

default-src 'none' — запрещено всё по умолчанию

Никаких трекеров, аналитики, рекламных пикселей

Никаких обращений к серверам

Все данные (данные пациента, отметки навыков, ответы на шкалы, тема) хранятся в localStorage браузера и не покидают устройство.

Возможности
Данные пациента. ФИО, дата, возраст, пол, ID, диагноз. Сохраняются в localStorage, подставляются во все модули.

Расчёт шкал. Мгновенный подсчёт баллов и интерпретация — при каждом клике.

Экспорт. Промпт для LLM (с ролью «ассистент невролога») и CSV-строка для Excel. Обе копируются одной кнопкой.

Печать. Ctrl+P — адаптировано под A4. Скрывает интерфейс, оставляет карту осмотра.

Тёмная и светлая тема. Автосохранение выбора. Учитывает prefers-color-scheme.

Автосохранение. Отметки навыков, ответы на шкалы и поля пациента восстанавливаются при перезагрузке.

Известные ограничения
PSQI. Реализованы 7 компонентов с оригинальными формулами, но без отдельных полей «время отхода ко сну» и «время пробуждения». Формула C4 (эффективность сна) использует шкалу длительности как прокси. Для полного соответствия оригиналу Buysse (1989) эти поля требуют отдельной доработки.

Пороги интерпретации. Все пороги — справочные. Русскоязычные пороги HADS (9 — депрессия, 10 — тревога) указаны в шпаргалке отдельно.

Печать. В диалоге печати обязательно включите «Фон и графика» — иначе цветовые акценты интерпретаций не отобразятся.

Дисклеймер
Этот инструмент — образовательный и методологический. Он не заменяет:

клиническое суждение врача

знание действующих клинических рекомендаций

формальное медицинское образование

Все формулировки носят справочный характер. Клинические решения принимает врач с учётом конкретной ситуации.

Не загружайте в публичные LLM персональные данные пациентов. Не используйте инструмент как единственный источник клинических решений.
