ℹ️О системе

VanXo Medical Kit — единый офлайн-инструмент для врача. Объединяет шесть модулей в одном HTML-файле: ассистент клинической коммуникации, неврологические и вертебрологические шкалы, психо-скрининги, офлайн-утилиты и база знаний.

Архитектура

Формат
Один HTML-файл. Работает без интернета, без сервера, без установки.
Данные
Хранятся локально (localStorage + IndexedDB). Не покидают устройство.
CSP
default-src 'none' — приложение физически не может отправить данные никуда.
Зависимости
Ноль. Только встроенные API браузера.
Seed IR
SHA-256 идентификатор сессии для переноса между устройствами.
Печать
Ctrl+P — адаптировано под A4. Скрывает интерфейс, оставляет карту.

Верификация шкал

Все девять шкал сверены с авторитетными источниками. Для PSQI реализованы оригинальные формулы Buysse (1989). Для шкалы Тампа применена инверсия пунктов 4, 8, 12, 16. Для PCS исправлен маппинг субшкал по Sullivan (1995). Для HADS максимум субшкалы = 21. Использованы валидированные русскоязычные версии, где они доступны.

Ограничения

Важно. Инструмент предназначен для научной и клинической работы. Не содержит медицинских рекомендаций — только шкалы и расчёт. Интерпретация носит справочный характер. Клинические решения принимает лечащий врач.
